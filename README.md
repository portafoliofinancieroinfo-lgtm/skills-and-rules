# Skills para Gemini / Antigravity

Repositorio público de skills reutilizables para agentes de desarrollo (Gemini / Antigravity / Claude Code).

## Skills incluidas

| Skill | Descripción | Ruta |
|---|---|---|
| `skill_map` | Genera un prototipo HTML comentable de solo lectura (estilo Figma) para el proyecto abierto en ese momento, con pines, agrupación y exportación en Markdown. | [`skills/skill_map/SKILL.md`](skills/skill_map/SKILL.md) |

## Instalación rápida

- **Por proyecto:** copia la carpeta `skills/<nombre_skill>/` dentro de `.agents/skills/` en tu repositorio.
- **Global (Antigravity):** copia o enlaza `skills/<nombre_skill>/` dentro de `~/.gemini/config/skills/`.
